# 🌐 Fnetic Website

**Fnetic** is a modern website built for the organization **Fnetic** ([https://fnetic.pl/](https://fnetic.pl/)), showcasing their services in software development, DevOps, cloud infrastructure, and cybersecurity.

The site serves as both a **company presentation platform** and a **client entry point** for starting new projects.

---

## 💡 Overview

Fnetic is a **DevOps-first software house** focused on building scalable systems, secure infrastructure, and high-performance applications. ([fnetic.pl][1])

The website was designed to clearly communicate:

* what the company does
* what technologies they use
* how clients can work with them

---

## 🧱 What the Website Represents

The website highlights Fnetic’s core areas:

### 💻 Custom Software Development

* Backend & frontend applications
* APIs and microservices
* Scalable architectures

### ☁️ DevOps & Cloud

* CI/CD pipelines
* Kubernetes & Docker
* Cloud infrastructure (AWS / Azure)

### 🔐 Cybersecurity

* Security audits & pentesting
* DevSecOps practices
* Infrastructure hardening

All of these are part of Fnetic’s offering as a **full-cycle technology partner**. ([fnetic.pl][1])
